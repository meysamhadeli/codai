Codai is an open source coding agent for your terminal. It works from the full context of your
project, reads and edits real files through tools, runs your commands, and asks before
anything changes.

Start with [Agent mode](./agent-mode/) to see what each mode allows, then add
[skills](./skills/) and [MCP servers](./mcp/) as you need them.

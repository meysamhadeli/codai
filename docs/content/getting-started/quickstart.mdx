# Quickstart

Install the tool, connect a model, and start with a small task. No project-wide
indexing step is required before the composer opens.

## Prerequisites

- [.NET SDK 10.0 or later](https://dotnet.microsoft.com/download).
- A project directory to work in.
- A model provider, or a local model server such as Ollama.

<Steps>

### Install Codai

```bash
dotnet tool install --global Codai
```

Update later with `/update` inside Codai, or use `dotnet tool update --global Codai`.
The in-app command checks nuget.org, offers **Update** or **Skip** when a newer
stable release exists, and reports when your version is already up to date.
Restart Codai after installation. See [update requirements](/usage/terminal#updates).

### Open your project

```bash
cd your-project
```

### Start Codai

```bash
codai
```

First review the **Workspace access** screen. **Yes** is selected first;
press Enter only when you trust the displayed directory. **No** or Escape leaves
without opening the workspace. Directory trust is separate from tool approval.

The first unconfigured run then asks for a theme, a provider, and a model, then **Save** or
**Cancel**. After saving, chat starts immediately. Settings are written to
the existing project configuration when one is selected; otherwise they use
`~/.codai/.codai.json` and are reused by other unconfigured projects.

<Callout type="warning">
  Own-provider credentials are stored as plaintext in the configuration file.
  Keep that file private and out of version control.
</Callout>

### Return later

```bash
codai
```

Directory access is requested on every launch; trust is not remembered. The saved
theme, provider, and model are reused without setup prompts. Use `codai auth` to
change the connection, or `:preferences theme` in a session to change the theme.

</Steps>

## Explore before editing

Plan mode reads and searches without writing files or running commands.

```bash
codai --trust-directory --mode plan "Explain this project and propose a small improvement"
```

Agent is the default mode. Change modes in a session with `/agents plan` or
`/agents agent`, or press Tab when no completion is visible.

## Complete a small task

Start with a change whose behavior you can check, and expand action steps to read
diffs and test output. Interactive sessions start with automatic tool approval.
For individual review of writes and commands, launch `codai --auto-approve false`
or press Shift+Tab to select Manual approval. Plan remains read-only in either case.

## Pick up where you left off

```bash
codai code --continue
```

Use `/session` for saved conversations, or the top tab strip to open and switch
independent conversations without losing drafts. See [sessions and recovery](/usage/sessions).

# Quickstart

## Prerequisites

- [.NET SDK 10.0 or later](https://dotnet.microsoft.com/download).
- A project directory to work in.
- Access to a supported model provider, or a local model server.

<Steps>

### Install Codai

```bash
dotnet tool install --global Codai
```

Already installed? Update with `dotnet tool update --global Codai`.

### Open your project

Run Codai from the directory containing your project so it can discover project guidance.

```bash
cd your-project
```

### Set up and start Codai

```bash
codai
```

On the first unconfigured run, choose **Graphite**, **Forest**, or **Ember**.
Codai saves the theme, then opens connection setup.
Choose **Use your own provider** for a hosted provider or local server, or
**Continue with ChatGPT** for an eligible account. Select a model and confirm before
saving. Chat starts immediately after saving. Escape returns to the previous step;
exiting connection setup preserves your saved theme for the next run.

Without an existing project configuration, settings are saved in
`~/.codai/codai-config.json` and reused across projects automatically. An existing
project configuration or explicit configuration directory keeps its own settings.

<Callout type="warning">
  Own-provider credentials are stored as plaintext in the selected configuration file.
  Keep that file private and out of version control. Remote credentials require HTTPS;
  loopback servers may use HTTP.
</Callout>

### Return later

```bash
codai
```

The saved theme, provider, and model are reused without setup prompts. Run
`codai auth` only to change the connection, or `:preferences theme` within a session
to change appearance. `codai code` also starts a session with the saved settings.

Describe a concrete task. Review proposed file changes and commands before approving
them. Use `:help` to list session commands and `@src/Foo.cs` to attach a file.

</Steps>

## Explore before editing

Plan mode reads and searches without writing files or executing shell commands.

```bash
codai --mode plan "Explain this project and propose a small improvement"
```

Agent is the default mode. In an interactive session, use `:mode` to change modes.
See [Agent mode](/agent-mode) for shell permissions and approval controls.

## Pick up where you left off

```bash
codai code --continue
```

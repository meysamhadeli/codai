## Start with a clear workflow

<Steps>

### Open your project

Run `codai` from your repository. First-run setup saves a theme and connection;
later runs open chat with those settings.

### Describe the outcome

Name the behavior, constraints, and checks that matter. Attach a file with `@path`
when you know where the work belongs.

```text
Find why empty configuration values pass validation.
Add a regression test, fix the parser, and run the relevant checks.
```

### Review the work

Inspect proposed commands and edits before approval. Expand action steps to read
results and diffs. Continue, refine, or restore deliberately.

</Steps>

# Build with Codai

<div className="codai-lead">

Codai is an open source coding agent for your terminal. Explore a codebase, plan a change,
and work across files with explicit approval for writes and commands.

## From idea to working code

<Steps>

### Install

Use the .NET SDK 10.0 or later to install the terminal tool.

```bash
dotnet tool install --global Codai
```

### Connect

Choose your provider and model through the guided setup.

```bash
codai auth
```

### Build

Start a session from your project directory.

```bash
codai code
```

</Steps>

<Callout type="info">
  Start with `codai --mode plan "Explain this project"` to explore without changing files
  or running shell commands.
</Callout>

## Stay in control

Plan mode reads and searches without writing files or running commands. Agent mode can
edit files and, when shell access is enabled, run commands under your approval policy.
Long sessions compact context; `codai code --continue` resumes a previous session.

Sessions discover project files on demand instead of building a full-project index at
startup. Project guidance still reaches the model before it starts work.

Read the [Agent mode guide](/agent-mode) for permissions, terminal controls, recovery,
and session commands. See the [roadmap](/agent-mode-roadmap) for work still in progress.

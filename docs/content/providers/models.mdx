# Choose a model

Choose a provider first, then a model offered by its endpoint. The same model
family can have different identifiers, availability, pricing, and transport
requirements across providers.

## Saved or session-only?

| Action | When it applies | Saved for later? |
| --- | --- | --- |
| `codai auth` model selection, then Save | Next session; first-run setup opens chat | Yes |
| `:preferences provider`, Default model, then Save | Next startup | Yes |
| `/auth`, then Save | Next startup | Yes |
| `/models`, then Enter, or `/models <model-id>` | Future requests in the current mode | No |
| `--model <id>` | This invocation | No |

<Callout type="info">
  The session model selector applies immediately on Enter; it does not have a
  Save / Cancel confirmation. Escape closes it before selection. Provider setup
  and saved-default edits require Save.
</Callout>

Inspect or change the mode-specific selection:

```text
:model
/agents plan
/models qwen3-coder
```

`/models` retains the active provider, endpoint, credential, and account reference.
Its picker offers bundled suggestions and a custom ID, not live discovery.
Suggestions appear in one flat numbered list, with a checkmark beside the current
model and no Recent/Favorites/provider headings. Recent and favorite choices
still affect ordering. Ctrl+F adds or removes the highlighted
model from Favorites; Ctrl+A opens provider setup. Recents and favorites are not
persisted across processes. The picker does not label unknown model pricing as free.
Use `/auth` or `codai auth` to authenticate provider connections, then restart.
Legacy `:model` remains callable but is not part of slash completion. Changing
the selection does not authorize a new credential or grant tool access.

## Live discovery

Setup asks the selected endpoint for its model catalog where supported.
It prefers that response to bundled suggestions, including for models released
after Codai was installed.

| Label | Meaning |
| --- | --- |
| Discovered model | Reported by the endpoint; not a guarantee of tool support |
| Saved model | Current configured selection retained in the picker |
| Suggested model | Bundled fallback; account access or installation is unverified |
| Custom model ID | A manually entered identifier |

Successful discovery is not padded with bundled models. Failed or empty discovery
uses suggestions where appropriate and still allows manual entry.

OpenAI-compatible APIs and Anthropic follow `has_more` / `last_id` pagination;
Gemini follows `nextPageToken`. Ollama lists installed models.
Discovery rejects repeated/missing cursors and catalogs beyond 100 pages or
10,000 entries instead of silently showing an incomplete list.

Duplicate and invalid IDs are removed, along with explicitly retired or non-chat
entries where metadata supports filtering. Gemini entries must support
`generateContent`; OpenRouter batch-only and non-text-output entries are excluded.
Model listing is not a chat or coding-tool test.

## Compatibility boundaries

| Connection | Important limit |
| --- | --- |
| OpenAI API-key connection | Uses Chat Completions; direct GPT-6 tool calling requires Responses API |
| Anthropic native adapter | Multi-turn tool use requiring thinking-signature replay is not supported |
| Azure OpenAI | Enter a deployment ID, not a public model name; deployments are never guessed |
| Ollama | Select a model installed on the selected server |
| ChatGPT account | Uses account-specific models, separate from API-key fallback suggestions |

Use the [supported defaults](/providers#supported-providers) when unsure.
An explicitly saved model is not replaced when a bundled default changes.

## Bundled fallback families

Fallbacks are convenience suggestions, not an exhaustive catalog. Account, region,
endpoint, and model lifecycle can change availability.

| Provider | Additional suggestions |
| --- | --- |
| OpenAI | GPT-6 variants, GPT-5.5 / 5.4 / 5.2 / 5.1 / 5, GPT-4.1 variants |
| Anthropic | Sonnet / Opus / Haiku 5.5, Fable 5.2 / 5.1, 5-series and selected 4-series models |
| Gemini | 4 Carbon / Argon, 3.6 Flash, 3.5 / 3.1 Flash Lite, Pro / Flash previews |
| DeepSeek | `deepseek-v4-pro` |
| OpenRouter | Provider-qualified OpenAI, Claude, Gemini, DeepSeek, Qwen, Mistral, and Grok families |
| Qwen | Qwen3.8 Max / Flash, Qwen3 Coder Flash |
| Mistral | Small 4, Codestral, Ministral variants; Large 4 is the default |
| Grok | 4.6 / 4.5 / 4.3, 4.20 variants, Grok Build 0.1 |

Azure has no guessed deployment suggestions. SDK hosts can inspect
`ProviderDescriptor.DefaultModel` and `SuggestedModels` for exact bundled IDs.

Suggestions were reviewed against provider catalogs on **November 10, 2026**.
Gemini 2.5 choices are no longer recommended for new connections; existing
configured IDs and historical prices remain usable subject to provider access.
Qwen suggestions focus on verified text/coding choices rather than older aliases
or Omni variants. Mistral no longer defaults to deprecated Medium 3.5.
Changing these suggestions does not migrate saved connections.

## Context limits and compaction

Every bundled hosted default and suggestion has provider-qualified context
metadata, reviewed separately from prices on **November 10, 2026**. Setup's live
model listing does not update this offline snapshot or infer limits for custom IDs.

| Default model | Published context | Separate maximum input | Synchronous output ceiling |
| --- | ---: | ---: | ---: |
| OpenAI / model-named Azure `gpt-5.4-mini` | 400,000 | 272,000 | 128,000 |
| Anthropic `claude-sonnet-4-6` | 1,000,000 | Not separately recorded | 64,000 |
| Gemini `gemini-3.8-flash` | 1,048,576 | 1,048,576 | 65,536 |
| DeepSeek `deepseek-flash` | 1,000,000 | 1,000,000 | 384,000 |
| OpenRouter `openai/gpt-5.4-mini` | 400,000 | Not separately recorded | 128,000 |
| Qwen `qwen3.7-plus` | 1,000,000 | Not separately recorded | 128,000 |
| Mistral `mistral-large-4` | 1,000,000 | Not separately recorded | Not verified |
| Grok `grok-4.7` | 500,000 | Not separately recorded | Not verified |
| Local Ollama `qwen3-coder` | Server-dependent | Server-dependent | Server-dependent |

Input and output share context; the columns are not additive allowances. Native
GPT-6 / GPT-5.5 / GPT-5.4 use a 1,050,000-token combined window with a
922,000-token input ceiling. Native Gemini 4 Carbon / Argon use a shared
1,048,576-token window and the normal 65,536-token output ceiling, not optional
long-decode limits. Routed limits can differ from native APIs.

Manual and automatic compaction use the active provider/model's input ceiling
when published, otherwise its recorded context window. Output reserve, tools,
safety margins, and any smaller selected automatic window reduce the usable
allowance further. Unknown output caps retain bounded fallback headroom; they
are not treated as unlimited. See [Context and delegation](/usage/context).

SDK hosts can read `ModelPricing.MaxContextTokens`, `MaxInputTokens`, and
`MaxOutputTokens` through `EmbeddedPricingCatalog.Find(provider, model)`.
Zero means that a separate limit was not verified. `ResolvedProviderOptions`
applies the effective input ceiling and bounded output reserve. Legacy
`MaxTokens` metadata is unchanged and is not a combined-window field.
